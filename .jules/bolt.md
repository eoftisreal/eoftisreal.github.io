## 2024-10-10 - Zustand destructuring causes O(N) list re-renders
**Learning:** Destructuring a Zustand store entirely (e.g. `const { addItem } = useCartStore()`) in a list item component like `ProductCard` subscribes every single instance of that component to all state changes in the store. For stores like `useCartStore` or `useWishlistStore`, this means adding an item to the cart causes *every single product card in the grid* to re-render.
**Action:** Always use specific state selectors (`const addItem = useCartStore(state => state.addItem)`) when consuming Zustand stores in components that are rendered in lists or grids to prevent widespread re-rendering bottlenecks. Additionally, wrap such components in `React.memo` to prevent inherited re-renders from parent components.
