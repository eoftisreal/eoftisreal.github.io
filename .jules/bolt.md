## 2026-10-07 - [Zustand Store Destructuring in React Lists]
**Learning:** Destructuring an entire Zustand store (e.g., `const { addItem } = useCartStore()` ) inside a component rendered many times (like a `ProductCard` in a grid) causes severe performance bottlenecks. The component subscribes to the entire store state, so ANY change to the store (like adding an item, which changes the `items` array or total price) triggers a re-render of EVERY component in the grid, rather than just the ones that need it.
**Action:** Always use specific state selectors (e.g., `const addItem = useCartStore((state) => state.addItem)`) when extracting actions or specific values from a Zustand store, especially in components rendered within lists or grids. Additionally, wrapping complex list items in `React.memo` ensures they only re-render when their specific props change.
